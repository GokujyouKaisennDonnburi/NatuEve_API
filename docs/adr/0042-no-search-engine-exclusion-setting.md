# ADR-0042: 検索エンジンに載せない設定は作らず、全イベントを sitemap に載せる

- ステータス: Accepted
- 日付: 2026-11-04
- 関連: #262, #259, NatuEve_Web_Frontend#373, NatuEve_Web_Frontend#375, NatuEve_Web_Frontend#380

## コンテキストと課題

PBI70 で、イベントページを検索エンジンにインデックスさせる。インデックスされると、イベントの情報が届く範囲はサイトの利用者の外へ広がる。公開された生息地情報が採集や密猟に使われる問題は学術的にも指摘されている（Lindenmayer & Scheele, "Do not publish", *Science* 356(6340): 800-801, 2017）。

そこで、希少種の観察会などを検索エンジンに載せない設定が要るか、要るなら判定方法と対象時の扱いをどうするかを決める必要がある。

制約と前提は次のとおり。

1. **`events` に座標の列はない**。開催場所は自由記述の `location` だけで、ここに書かれた内容は公開 API とイベントページで誰でも読める。
2. **種の属性がない**。希少種を表す項目も種のマスタもない。タグは利用者が自由に作れる（`POST /api/v1/tags`）ので、種の判定の根拠にならない。
3. **イベントの編集 API がない**。設定を投稿後に変えるには、新しいエンドポイントが要る。
4. **`noindex` はアクセス制御ではない**。検索結果に出さないだけで、ページも API も誰でも読める。秘匿すべき情報を守る手段にはならない。

## 決定

**検索エンジンに載せない設定は作らない。全イベントを sitemap とインデックスの対象にし、主催者への注意喚起は投稿ガイドラインの注意書きにとどめる。**

1. 要否: 今は作らない。DB・API に設定や希少種の項目を追加しない。
2. 判定方法・対象時の扱い: 設定を作らないので定めない。希少種の項目を作る場合は別の PBI とし、そこで判定方法と扱いを決める。
3. sitemap: 全イベントを載せる（#259、NatuEve_Web_Frontend#373）。
4. 注意喚起: フロントの投稿ガイドライン（`/guideline`）に、生息地を特定できる情報を書かないよう注意書きを足す。

## 理由

- **希少種の項目は PBI70 の範囲外である**: 主催者が選ぶ方式でも、DB・投稿 API・変更用のエンドポイント・投稿画面・メタデータの出し分けが要る。自動判定には種のマスタも要る。検索エンジン対策の PBI に含める規模ではなく、作るなら別の PBI で扱う。
- **設定を作っても、書かれた情報は隠せない**: `noindex` は公開されたページや API の内容を守らない。生息地を守るうえで効くのは、特定できる情報を公開情報に書かないことであり、それは投稿ガイドラインで主催者に伝えられる。

## 影響（結果）

### 良い影響

- DB・API・フロントの追加実装がなく、#259 と NatuEve_Web_Frontend#373 は全イベントを対象にそのまま進められる。
- 主催者が設定し忘れた場合の扱いや、投稿後の変更手段を考えなくてよい。

### トレードオフ・制約

- **主催者の判断に依存する**: 注意書きに強制力はない。生息地を特定できる内容が投稿されれば、そのままインデックスされうる。
- **検索エンジンから個別に外す手段がない**: 投稿後に問題が分かっても、製品上の手段はない。
- **一度インデックスされると残る**: 後から `noindex` や削除で対応しても、再クロールまで検索結果に残ることがある。Google は再訪に数か月かかることがあるとしている（[Block Search Indexing with noindex](https://developers.google.com/search/docs/crawling-indexing/block-indexing)）。

## 検討した代替案

- **主催者が投稿時に選ぶ**: 投稿時に非掲載を選べるようにする / DB・API・投稿画面の変更が要り、イベントの編集 API もないため変更用のエンドポイントも要る。範囲が PBI70 を超えるので不採用。
- **種の属性で自動判定する**: 希少種フラグに紐づけて非掲載にする / 種の属性もマスタも存在せず、タグでは代用できない。不採用。
- **主催者の選択と自動判定を組み合わせる**: 上の 2 案の併用 / 両方の負担が要るため不採用。
